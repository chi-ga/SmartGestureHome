=== 通信协议定义表 ===
波特率: 9600
数据位: 8
停止位: 1

[手势映射指令]
1.  张手 (Palm Open)      -> 发送字符: 'A' -> 功能: 灯光开启 (LED ON)
2.  握拳 (Fist)            -> 发送字符: 'B' -> 功能: 灯光关闭 (LED OFF)
3.  剪刀手 (Victory)       -> 发送字符: 'C' -> 功能: 窗帘打开 (Servo 180度)
4.  单指 (One Finger)      -> 发送字符: 'D' -> 功能: 窗帘关闭 (Servo 0度)
5.  OK手势 (OK)            -> 发送字符: 'E' -> 功能: 风扇开启 (Fan ON)
6.  点赞 (Thumbs Up)       -> 发送字符: 'F' -> 功能: 风扇关闭 (Fan OFF)
7.  三指 (Three Fingers)   -> 发送字符: 'G' -> 功能: 电视开启 (TV ON)
8.  四指 (Four Fingers)    -> 发送字符: 'H' -> 功能: 电视关闭 (TV OFF)
9.  摇滚 (Rock)            -> 发送字符: 'I' -> 功能: 空调开启 (AC ON)
10. 小指 (Pinky)           -> 发送字符: 'J' -> 功能: 空调关闭 (AC OFF)
11. 打电话 (Call Me)       -> 发送字符: 'K' -> 功能: 音响开启 (Audio ON)
12. 竖中指 (Middle Finger) -> 发送字符: 'L' -> 功能: 音响关闭 (Audio OFF)
